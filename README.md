# Casa MZX

Site institucional da Casa MZX, salão de beleza no Tatuapé, São Paulo.

## Estrutura

- `index.html`: conteúdo e estrutura da página.
- `assets/css/style.css`: estilos responsivos.
- `assets/js/app.js`: menu mobile, animações e fluxo de agendamento.
- `assets/img/`: imagens locais usadas pelo site.

## Execução local

Como o projeto é estático, abra `index.html` em um navegador ou sirva a pasta com qualquer servidor HTTP local.

## Observações

O formulário monta uma mensagem de preferência e abre o WhatsApp para confirmação da equipe. Ele não confirma disponibilidade automaticamente.
